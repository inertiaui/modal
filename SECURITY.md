# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/inertiaui/modal/security/advisories/new) or email `pascal@protone.media`.

Do not open public GitHub issues for security reports.

Expect an initial response within 72 hours. Once confirmed, a fix and coordinated disclosure timeline will follow.
